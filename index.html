Coding for Kids

My First Code

The first book, and the first line of code. Big pictures, one idea to a page, and a friendly robot who sticks around while a five year old works out that a computer does exactly what it is told.

  • Starts with coloured blocks, so nothing has to be typed or spelled
  • Scratch first, then code.org, then programs that are all their own

Book two · Ages 9+

Coding for Teens

My First Code

The same ladder, a longer climb. Real projects instead of exercises, logic explained rather than demonstrated, and enough independence that they stop asking what the next step is.

  • Projects that get finished, not exercises that get abandoned
  • Loops, conditionals and functions in plain English, no jargon

Robotics, 3D design and Arduino
